# GEO Scan — аудит AI/GEO-готовности сайта

Веб-приложение проверяет публичный сайт эвристиками: насколько он удобен для обнаружения, понимания и цитирования **ChatGPT**, **Yandex Alice/Neuro**, **Gemini** и **Perplexity**.

Это **не гарантия** ранжирования в ответах ИИ — оценка готовности и вероятности.

## Стек

- Vite + React + TypeScript (UI)
- Express (серверный fetch и анализ HTML)
- Cheerio (разбор разметки)

## Запуск локально

```bash
npm install
npm run dev
```

- UI: http://localhost:5173  
- API: http://localhost:8787  

Откройте UI, вставьте URL и нажмите **Проверить**.

### Production

```bash
npm run build
npm start
```

Сервер отдаёт собранный UI из `dist` и API на порту `8787` (или `PORT`).

## Что проверяется

1. **Архитектура** — главная, о компании, услуги, база знаний, кейсы, локации, FAQ  
2. **Качество контента** — факты, H1, цены в HTML, кейсы с метриками, команда, trust  
3. **Письмо для ИИ** — прямой ответ, конкретика, пояснения, доказательства, Q&A, CTA  
4. **Техника** — robots.txt (Googlebot / OAI-SearchBot), noindex, sitemap, meta/H1, внутренние ссылки, Schema.org, контент не JS-gated  
5. **Покрытие запросов** — бренд / категория / сравнение / коммерция  
6. **FAQ и локальность** — FAQ, адрес, часы, отстройка  
7. **Бонус** — `llms.txt` (слабо влияет на балл)

Результат: общий балл 0–100, баллы по столпам, чеклист ок/внимание/критично с рекомендациями на русском и топ-5 «что исправить сначала».
